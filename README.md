### Доступность и удобство использования

Для повышения доступности и удобства использования формы сделано следующее:

- добавлены примечания для скринридеров о том какие, действия можно выполнить и использованы семантические тэги;

- подобрана триада цветов, которые согласно источникам воспринимаются всеми людьми одинаково хорошо и достаточно контрастны и приятны всем людям;

- выбран удобный и понятный шрифт для текста на странице;

- размер шрифта всегда достаточно велик для удобного чтения и снижения напряжения глаз;

- добавлена возможность автозаполнения по сохранённым в браузере данным;

- при наведении курсора на элементы ввода и кнопки входа форма реагирует, чтобы пользователь понимал, что "что-то полезное происходит";

- сделано удобное спокойное пролистывание страницы;

- размеры шрифта вычисляются в зависимости от размеров экрана;

- повышено удобство при работе со страницей с клавиатуры.
